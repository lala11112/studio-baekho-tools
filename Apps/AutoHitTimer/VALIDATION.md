Unity 시험은 저장소의 `.test-unity/AutoHitTimerValidation`에서 수행했습니다. 원본 게임에는 변경하지 않았으며, 게임 데이터 타입 9개·원본 FBX·Avatar·검을 복사한 최소 검증 프로젝트입니다. 원본 전체 게임 씬이나 Combat Lab 의존성을 복원한 전체 게임 통합 시험을 대신하지 않습니다. 실제 촬영 호출 방식과 재현 방법은 공용 패키지 README에 기록합니다.

어댑터 회귀에는 단타·다단타 매핑, 기존 피해·피드백 보존, 신규 0/0 상속, 타수 변경, 미지원 폼, 상태 속도·오프셋·연속 재사용, 시간 보정, 충돌, Undo, 새 폴더 복사, 신규 상태 연결, 중복 적용, 주입한 실패 롤백, 읽기 전용 저장 상태 조회가 포함됩니다.

중단 복구 시험에서는 요청 전 앱 종료, 완료된 어댑터 저널과 중단된 브리지 응답의 불일치, 복구 필요 상태를 구분합니다. 저장을 재전송하지 않고 저널의 `complete`를 확인하면 성공으로 복원하며 `preview`/`rolled-back`만 편집 잠금을 해제합니다. 손상 초안은 별도 `.corrupt` 파일로 보존합니다.

## 실제 AI 결과의 의미

`straight_sword_th_light_attack_01` (1.666667초)를 검증용 `Md_Char_Low_Poly_Man` Avatar 모델, 단색 머티리얼, 기본 검 부착 회전으로 촬영했습니다.

- 24fps 분석 후보: **0.458333–0.666667초**, 1타.
- 60fps 경계 재분석: **0.483333–0.616667초**, 1타, **불확실**.
- AI는 재분석에서 검과 손의 위치가 어긋나 보인다는 이유를 반환했습니다. 임시 검 부착 설정의 한계와 일치하며, 게임의 올바른 타격 구간이라는 근거로 사용하지 않습니다.

실제 PNG·프레임 ID·타임스탬프, `real-ai-result.json`, `real-ai-refined.json`은 별도 검증 프로젝트에 보존합니다. 게임 원본 자산과 개인 로그인 정보는 배포물에 포함하지 않습니다.

**사람 기준의 타수 일치율·경계 오차는 아직 측정하지 않았습니다.** 사람이 라벨링한 대표 공격 데이터가 필요합니다. 24/60fps는 촬영 주기이며 AI 정확도 수치가 아닙니다. 단타 외 다단타·무타격·빠른 경계 타격의 실제 AI 평가와 전체 게임 플레이 확인도 남아 있습니다.

외부 FBX는 Unity 기본 임포트 설정으로 시작합니다. 확인한 외부 공격 FBX는 Generic 본 경로가 선택한 Humanoid 모델과 달라 사유와 함께 차단되었습니다. 이런 파일은 Unity에서 올바른 Rig/Avatar 설정을 적용한 뒤 다시 검색해야 합니다.

## 사람 기준과 비교하기

`scripts/evaluate.cjs`는 사람 기준과 편집 전 실제 AI 결과를 클립 GUID/하위 에셋 ID로 대응시킵니다. 입력 형식은 다음과 같습니다. 아래 값은 형식 예시이며 평가 결과가 아닙니다.

```json
{
  "clips": [{
    "guid": "0123456789abcdef0123456789abcdef",
    "localId": "7400000",
    "reviewer": "검토자 이름",
    "windows": [{"start": 0.2, "end": 0.4}]
  }]
}
```

AI 입력도 같은 `clips` 형식이며 `reviewer` 대신 `source: "real-ai-unedited"`를 기록합니다. 실제 분석 결과를 수동 편집하기 전에 내보낸 값이어야 합니다. 모의 결과는 정확도 평가 입력으로 사용할 수 없습니다.

```powershell
node scripts/evaluate.cjs human.json real-ai.json report.json
```

타수 일치율, 평균·최대 경계 절대 오차(ms), 누락 클립 수를 기록합니다. 경계 오차는 타수가 같은 클립의 시간순 대응에 한정합니다. 타수가 다른 클립을 임의로 연결하지 않으며, 누락은 분모에서 제외하고 별도로 표시합니다.
