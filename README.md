# 스튜디오 백호툴

스튜디오 백호 게임개발팀의 업무 자동화 도구를 모으는 작업 공간입니다.

**공통 탐색·작업 상태·결과 보관은 일관되게 만들고, 각 도구의 내부 UI와 작업 구조는 팀원들이 만든 작업물을 활용합니다.** 사용자가 도구를 바꿔도 기본 조작을 다시 배우지 않는 것을 우선합니다.

현재 개발 중인 대표 도구는 **타격감 찾기 자동화**, **모델링 자동화**입니다. 이 저장소의 문서는 연결 원칙과 디자인 참고 자료이며, 해당 기능의 구현 완료를 의미하지 않습니다.

## 합의한 사용 흐름

**도구 선택 → 도구 작업공간 → 결과 확인·보관 → 이어서 작업**

- 공통 메뉴는 `홈 / 도구 / 실행 / 결과 / 설정`을 기준으로 합니다.
- 도구 작업공간 안의 단계, 입력 폼, 편집기, 미리보기 배치는 담당 팀이 설계합니다.
- B 작업실형의 도구 탐색을 기본 입구로, A 관제형의 작업 목록을 실행 화면으로 사용합니다.
- C 파이프라인형은 여러 도구를 연결할 실제 요구가 생겼을 때 검토합니다.

## 기존 도구를 연결하는 순서

1. 담당자는 기존 작업물을 유지하면서 [인계 양식](docs/templates/tool-handoff.md)을 작성합니다.
2. 공통 화면 담당자와 프로젝트 전달, 화면 복귀, 실행 상태, 결과 다시 열기 방식을 맞춥니다.
3. 지원하지 않는 동작은 사용자에게 정확히 안내하고, 필요한 개선을 별도로 기록합니다.
4. 다른 팀원이 설명 없이 도구 선택부터 결과 확인까지 해보는 사용성 점검을 거칩니다.

이 문서에서는 프레임워크, API, 백엔드, 패키지 구조를 확정하지 않습니다. 실제 연결 방식은 각 도구의 현재 구현을 확인한 뒤 결정합니다.
