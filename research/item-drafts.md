# 사인검 아이템 20개 검토용 초안

작성일: 2026-10-12 · 상태: **제안·검토 대기**

이 문서는 기존 기획의 20개 아이템을 그대로 가져온 검토 자료다. 제품 코드, 이미지, Unity 에셋을 생성하지 않았다. 이름·ID·효과·수치·설명·아이콘 모티프를 채택한 것으로 간주하지 않으며, 작성·생성·저장 요청과 게임 밸런스 승인을 구분한다.

## 확정 규칙과 제안의 경계

| 구분 | 확정 규칙 | 검토 대기 또는 미정 |
| --- | --- | --- |
| 제작 규모 | 목·화·토·금·수 5오행 × 등급 1~4, 각 칸 1개, 총 20개 | 각 칸에 들어갈 아이템의 이름·ID·개별 효과 |
| 가격 | 등급 1/2/3/4의 구매가 20/40/80/160골드, 같은 등급은 같은 가격 | 가격을 효과의 강도에 맞추어 임의 변경하지 않음 |
| 필수 데이터 | 고유 ID·이름·아이콘·설명·등급·가격·효과와 값·시너지 판정 정보·고정 오행 | 실제 ID 문자열·아이콘 키 규칙·파일·구체 태그·설명 문구 |

| 중복 | 현재 보유 중인 같은 ID는 최대 1개, 이미 보유한 ID는 상점·보상 후보에서 제외, 한 목록 내 중복 후보 금지 | 원문 요약의 ‘런당 최대 한 개’를 ‘그 런에서 재획득 영구 금지’로 확대 해석하지 않음 |

| 시너지 | 조건 아이템 동시 보유 시 자동 발동, 복수 시너지 동시 적용, 판매·합성 소비로 조건 해제 시 종료, 제작 규모 5조합 | 정확한 ID 조합·개별 효과·태그·합산 방법 |
| 후보와 합성 | 일반/상점 등급 가중치 50/30/15/5, 보스 3/4등급 80/20, 빈 등급 제외·재정규화. 서로 다른 3등급 2개+2등급 1개 → 선택 오행 미보유 4등급 1개, 추가 골드 없음, 결과 없으면 재료 보존 | 최초 상점 분포·등급 내 선택법·보스 후보 완전 소진·재입고/재방문 규칙 |
| SP 기준 | 최대 100, 시작 시 가득, 소비 후 1초 지연·초당 20 재생, 회피 비용 20·전환 비용 10, 전환 공통 쿨타임 2초 | 아이템의 가산량, SP 상한 200·재생 상한 40·회피 비용 하한 8·전환 비용 하한 4 |
| 효과 생명주기 | 사망·포기 시 런 아이템 초기화, 게임 일시정지 시 지속 효과·쿨타임 정지 | 소스별 버프 처리 세칙, 최대치 변화 시 현재 HP/SP 처리, 최종 클리어 후 런 자원 처리 |

등급·가격·20개 구성은 확정 규칙 검증 대상으로 둔다. 제안값이 바뀌었다는 이유만으로 규칙 위반으로 차단하지 않는다. 특히 상한·비용 하한은 ‘현재 초안의 산술 점검’으로 표시하고, 확정된 게임 규칙으로 승격하지 않는다.

### 아이콘 처리의 경계

- 원문의 `IconKey = icon.<ID>`는 임시 데이터 키 제안이다. 예: `icon.IT_WOOD_01`. 실제 이미지 파일 존재를 뜻하지 않는다.
- 표의 모티프는 오브젝트와 실루엣만 제안한다. 기존 아트 조사 전에는 화풍·재질·팔레트·해상도·테두리·배경·시점을 확정하지 않는다.
- 같은 ‘매듭’·‘인장’·‘장식’ 이름이 여러 오행에 등장하므로 작은 카드에서도 물체 형태와 중심 모티프가 구분되는지 검토한다. 오행과 등급은 UI 표시와 그림을 분리해 검토할 수 있다.
- 아이콘은 아직 생성되지 않았다. 실제 생성 수단·비용·입력 참조 이미지·파일 전달 경로는 상위 설계의 도구 조사 결과를 따른다.

## 공통 효과 세칙 — 모두 제안·검토 대기

| 항목 | 원문 제안 |
| --- | --- |
| 적용 범위 | 모든 행은 소지 중에만 유효하며 모든 폼에 적용. 아이템 오행은 획득 풀·시너지 분류이며 폼 사용 제한이 아님 |
| 성공 전환 | 던전에서 SP 결제와 실제 다른 폼으로 변경이 완료된 `OnFormSwitchSucceeded` 사건. 같은 폼 선택·SP 부족·쿨타임·행동 제한·허브 선택은 제외 |
| 상시·시간제 효과 | 소스 ID별 1중첩. 시간제 효과 재발동은 3초로 갱신하며 시간이나 수치를 누적하지 않음. 일시정지 중 경과하지 않음 |
| 소스 제거 | 판매·합성 소비·런 초기화로 상시 효과와 잔여 버프 모두 즉시 제거. 재획득이 지워진 버프를 복원하지 않음 |
| 합산 | 같은 종류의 서로 다른 소스는 가산. 피해 종류별 가산을 분리. HP·피해의 `%`는 가산 보정률, SP/초와 SP 비용 감소는 절대량 |
| 최대치 변화 | 최대 HP/SP 증가가 현재 자원을 지급하지 않음. 감소 시 새 최대치를 넘는 현재 값만 제한 |
| 태그 | 목 `ITEM_WOOD`, 화 `ITEM_FIRE`, 토 `ITEM_EARTH`, 금 `ITEM_METAL`, 수 `ITEM_WATER`. 태그 자체에 효과 없음 |
| 시너지 판정 | 아래 정확한 아이템 ID 집합을 모두 보유하는지 판정. 태그 수량만으로 임의 대체하지 않음 |
| 발동 순서 | 입력·SP 확인 → SP 1회 차감 → 폼 변경·2초 쿨타임 → 전환 성공 사건 1회 → 해당 스킬 수치 고정·발동 |
| 제외된 효과 | 이 초안에는 즉시 SP 환급·추가 공격·추가 전환·치명타·상태 이상·처치 재화 증가 없음 |

SP 합산식 제안은 최대 SP `min(200, 100 + 가산 합)`, 재생 `min(40, 20 + 가산 합)`, 회피 비용 `max(8, 20 - 감소 합)`, 전환 비용 `max(4, 10 - 감소 합)`이다. **200·40·8·4는 확정 규칙이 아니다.** 재생 1초 지연·전환 2초 쿨타임·공통 회피 성능은 별도의 확정값이다.

## 강화·시너지 참조 — 이번 아이템 제작 범위 밖

강화 10종과 시너지 5조합은 참조만 유지한다. 이 문서에서 추가 아이템이나 강화·시너지 에셋을 만들지 않는다.

- 강화 10종 ID: `UP_COMMON_01`~`UP_COMMON_05`, `UP_WOOD_01`, `UP_FIRE_01`, `UP_EARTH_01`, `UP_METAL_01`, `UP_WATER_01`.
- 공통 5종+폼별 1종이라는 규모는 확정. 개별 이름·값·최대 레벨 3 및 이전 레벨 값을 교체하는 세칙은 제안이다.
- 아래 시너지의 5조합 규모·보유 시 자동 적용 원칙은 확정이지만, 이름·조합 ID·효과값은 제안이다.

## 필요한 기획 질문 최소 묶음

문서·초안 작성은 질문 답변 없이 진행 가능하다. 실제 채택 시 아래 두 묶음만 먼저 검토하고, 상점·런 구현의 미정사항은 이번 생성기 착수의 불필요한 선행 질문으로 확장하지 않는다.

1. **아이템 콘텐츠 채택:** 기존 20개 이름·효과·수치·3초 버프 및 공통 처리 제안을 초기 검토안으로 유지할지, 바꿀 행이 있는지 한 번에 검토한다. SP 상한/하한 `200·40·8·4`, 가산 방식, 최대치 변화 시 현재 자원 처리, 태그와 5개 시너지 ID 참조도 함께 검토하되 ‘아이콘을 만들고 초안 20개를 작성’ 요청을 수치 승인으로 해석하지 않는다.
2. **아이콘 방향:** 상위 조사에서 확인한 기존 사인검 아트 기준을 적용할지, 사용자 수정 사항이 있는지 검토한다. 기존 기준이 충분하면 별도 질문 없이 그 기준으로 구체안을 작성한다. 위 모티프는 승인된 스타일이 아니다.

전체 런 관련 미정인 보스 후보 소진, 최초 상점 분포, 재입고/재방문, 최종 클리어 후 자원 처리는 ‘이번 범위 밖·미정’으로 유지한다. 기존 전투 도구의 E스킬/R궁극기 입력과 새 기획의 숫자 폼 전환/E상호작용 충돌 역시 별도 범위다.

## 이 문서에서 확인한 결과

- 원문 아이템 20행의 이름·ID·오행·등급·가격·조건·효과·수치·지속·중첩/해제를 변경 없이 유지했다.
- 20개 ID는 서로 다르며 5오행 각각 등급 1~4를 정확히 한 개씩 가진다. 가격은 모두 확정 가격표와 일치한다.
- 아이콘 모티프 20개를 추가했지만 이미지·아트 스타일을 확정하거나 생성하지 않았다.
- Unity 실제 데이터형 존재 여부·내보내기 방식·생성 도구 및 전달 경로는 상위 담당 조사에서 결정한다. 이 문서는 존재하지 않는 `ItemDefinition`이나 ScriptableObject 타입을 가정하지 않는다.
