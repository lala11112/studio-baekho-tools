# 백호툴 0.10.0 · 3D·아이템·BGM 통합

0.9.0 통합 때 범위를 3D와 BGM으로 한정해 사인검 아이템 메뉴가 빠졌습니다. 0.10.0은 기존 아이템 브랜치까지 통합해 홈의 앞쪽에 **3D 모델링 → 사인검 아이템 → BGM 만들기**를 배치합니다. 기존 타격감·타격 타이밍 도구도 유지합니다.

## 소스와 전달

- 통합 브랜치: `integration/baekho-bgm`.
- 3D: `Auto-3D-Tool@7fbb5b9`의 최신 미리보기 수정 포함. UV 입력용 native FBX와 화면 미리보기용 GLB의 같은 ID 충돌을 해결한 원본 수정입니다.
- 아이템: `codex/saingeom-item-generator@16775d5`의 서비스·에디터·아이콘·검토·내보내기와 실제 예제 자산.
- BGM: `codex/bgm-generator@fa53929`의 Google Lyria 3 생성·재생·선택·내보내기.
- 원본 기능 브랜치, main, 이전 통합 브랜치를 수정하지 않습니다.

새 폴더 `Baekho-All-0.10.0`의 `Launch-Baekho.vbs` 또는 바탕화면 **백호툴 - 통합 작업실**로 실행합니다. `App`, `Data`, `OriginalDataSnapshot`, `Verification`을 함께 보관하세요. 기존 0.9.0 실행본과 사인검 전용 앱은 보존합니다. 저장하지 않은 입력을 잃지 않도록 기존 창을 강제로 닫지 않습니다. 각 실행본의 데이터는 이후 자동 동기화하지 않습니다.

기존 공용 저장소의 변경하지 않은 사본, 기존 BGM 세 곡 및 실제 사인검 저장소의 두 초안 묶음을 새 Data에 복사합니다. 실제 주 묶음 `93190cd9-a826-4b58-b257-cf4ba077b827`은 revision 72, 초안 20개·아이콘 20개이며 자동 채택하지 않습니다. 별도 편집 묶음 `369b23cb-4a95-4ff5-84cc-bd821b274cc6`도 보존합니다. 원본·복사본의 해시를 비교하며 기존 UUID가 있으면 덮어쓰지 않습니다.

아이템 작업자는 최신 프로젝트 지침에 따라 기존 Codex·MCP 설정을 상속합니다. API 키나 로그인 정보는 새 평문 파일로 저장하지 않습니다. 실제 아이콘 새 생성은 이번 검증에서 실행하지 않습니다.

## 사용

1. 홈의 **사인검 아이템**을 열고 기존 20개 초안 묶음을 선택합니다.
2. 아이템·아이콘을 확인하고 필요한 내용만 편집합니다. 내용 검토·아이콘 검토·최종 채택은 명시적인 별도 단계입니다.
3. **초안 내보내기**는 기존 상태 그대로 Unity용 JSON·PNG 묶음을 새 폴더로 저장합니다. 배포용 내보내기는 모든 항목 검토·채택 조건을 만족해야 합니다.
4. **BGM 만들기**에서 기존 세 곡을 듣고 선택해 MP3로 내보낼 수 있습니다. 이 동작은 생성 비용이 없습니다.

Unity 묶음은 JSON TextAsset와 PNG Texture2D/Sprite 반입 범위입니다. 실제 게임 전투 효과나 ItemDefinition/ScriptableObject 연동은 추가 구현이 필요합니다. 기존 유료 3D 제작이나 아이콘 생성 작업은 자동 재개하지 않습니다.

## 검증

최신 3D 미리보기 집중 테스트 1개와 아이템 집중 테스트 39개가 통과했습니다. 실제 전달 앱의 다섯 도구·20개 아이콘·초안 내보내기·세 곡 재생 및 재시작, Unity 반입의 최종 결과는 전달 폴더 `Verification`에 기록합니다. 앞선 0.9.0의 전체/집중 검사 이력은 [이전 통합 기록](BAEKHO-3D-BGM-INTEGRATION.md)에 보존합니다.

추가 유료 생성·재시도는 **0회**입니다. 기존 BGM의 3회 생성 예상 비용 USD 0.12를 그대로 유지하며 이번 통합은 추가 비용이 없습니다. Notion 기록 대상은 이전 조회에서 404였으므로 이 문서를 게시 대기 기록으로 보관합니다.
