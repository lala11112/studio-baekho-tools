# 레벨디자인 규칙과 검증 근거

2026-10-14에 공개 자료를 확인했습니다. 이 생성기는 근접 공격과 회피를 사용하는 단일 방의 블록아웃을 돕습니다. 공간 검사는 플레이 감각이나 재미를 보증하지 않으며 실제 게임 컨트롤러로 반복 플레이테스트해야 합니다.

## 컨셉과 설계도에 원칙을 전달하는 방식

`src/shared/level-design.ts`의 `LEVEL_DESIGN_PRINCIPLES`가 위 Metrics·Encounter·Flow 원칙과 방 용도별 적용 범위를 한곳에서 정리합니다. 컨셉·이미지·배치 추출 프롬프트가 같은 내용을 사용하며, 배포 앱에 포함된 코드로 전달하므로 실행 중 문서 파일이나 외부 웹사이트를 읽지는 않습니다. 문서 원문을 AI가 매번 직접 열람한다는 의미는 아닙니다.

- 컨셉은 방의 역할, 플레이 목표, 진입 전 판단, 접근·회피·이탈의 선택과 목적물 이용을 설명합니다. 시각적 테마·분위기·색감·재질·조명·장식과 좌표·중앙·외곽 등 구체적인 배치 지시는 제외합니다. 후보도 외형 대신 활성 기능 안에서 가능한 플레이 선택으로 차별화합니다.
- 이미지와 추출에는 공간 분석이 켜진 경우 기존 `compileLevelDesign`의 동일한 수치·패턴 레시피를 추가합니다. 분석을 끄더라도 일반 원칙은 전달하지만 수치·패턴에 대한 심화 검사는 켜지지 않습니다. 시작·보상·상점방에는 전투를 추가하지 않습니다.
- 설계도는 조건이 허용하면 외곽, 공간 비율, 고지·계단, 장애물, 신규 출입문 위치 중 최소 두 요소의 자연스러운 비대칭을 선호합니다. 출입·회피·연결성과 명시된 형태·수량·치수를 먼저 지키며, 단순한 방에 비대칭만을 위한 구조를 강제하지 않습니다. 후보의 편향 방향은 시드와 후보 번호로 정합니다.
- 추출은 이미지의 실제 대칭 또는 비대칭, 지형 위치와 높이를 보존합니다. 대칭을 줄이기 위해 추출 단계에서 지형을 다시 설계하지 않습니다. 부분 재생성에서는 잠금·영역 밖 셀과 기존 연결문을 유지합니다.

비대칭은 이 프로젝트의 생성 선호이며 문헌의 필수 법칙이나 생성 성공 조건이 아닙니다. 기존 컨셉·저장 맵·직접 입력을 자동으로 다시 쓰지 않으며 공개 API와 저장 형식은 유지합니다. 프롬프트 전달과 우선순위는 backend·level-design·variants 테스트, 실제 출력 품질은 별도 AI 생성 기록으로 확인합니다.

## 전투 소품의 역할과 변화

교전 공간은 입구에서 충분히 떨어진 뒤 방 중앙을 우선합니다. 입구에서 가장 먼 모서리에만 교전과 소품이 몰리지 않게 하며, 사용자가 지정한 전투 구역에는 우선권을 줍니다.

기존 개수 유지 모드에서 신규 전투방·보스방의 미지정 `P`는 소품 한 개의 의도입니다. 원본 이미지의 대칭 좌표를 고정하지 않고, 입구·회피·필수 경로를 예약한 다음 전투 공간 옆 접근 및 후퇴 구간을 우선 평가합니다. 실제 프리팹 점유 폭·깊이 전체에 대해 높이·머리 위 여유·잠금과 충돌을 확인하며 크기를 줄이지 않습니다. 생성된 장애물마다 서로 반대쪽을 지나는 두 국소 경로와 직선 대비 늘어난 이동 거리를 계산하고, 다음 소품과 시설이 그 경로를 막지 못하도록 예약합니다. 보고서와 오버레이에 이 경로와 우회 거리의 근거를 표시합니다. 이는 이동 선택을 확인하는 검사이며 원거리 공격의 엄폐·시야 차단 효과를 보증하지 않습니다.

좌우·상하·중심 대칭 위치에는 낮은 점수를 주되, 대칭 지형 자체를 금지하지 않습니다. 시드는 접근 방향과 가능한 회전을 결정합니다. 같은 조건에서 사용 가능한 종류의 출현 가중치와 누적 사용량을 함께 고려하여, 동일 가중치의 여러 종류가 있으면 한 종류로 반복되는 현상을 줄이고 매우 낮은 가중치의 희귀 소품을 억지로 포함하지 않습니다. 라이브러리 정렬을 바꾸어도 결과는 동일합니다.

이 대칭 위치 감점은 기존 개수 유지와 자동 균형 구성에서 공통으로 사용합니다. 안전한 위치가 대칭 위치뿐이면 사용할 수 있으며, 감점을 위해 원본 크기·점유 면적·통행·회피·우회 조건이나 기존 수동 배치를 바꾸지 않습니다.

장식과 식생은 별도 역할·토글·밀도를 사용합니다. 새 배치는 이미 놓인 장식·식생에서 떨어진 위치를 우선하고 종류와 회전을 변화시킵니다. 문에서 멀다는 이유로 한쪽 모서리에 계속 모이지 않도록 문 거리 점수의 영향을 제한합니다. 이는 분산 선호이며 높은 밀도에서도 고정된 최소 간격을 보장하는 조건은 아닙니다. ㄱ자·곡선 등도 배율·회전을 반영한 외접 직사각형 전체를 점유하며 오목한 빈 부분을 다른 소품에 재사용하지 않습니다. 측정된 크기가 첫 위치에 들어가지 않으면 자동 생성한 미지정 장식·식생만 다른 안전한 위치를 탐색합니다. 직접 지정한 프리팹과 수동 배치는 옮기지 않습니다.

이 과정은 AI 생성에서 새 배치를 결정할 때 사용합니다. 기존 인스턴스, 직접 지정한 프리팹, 잠긴 셀과 일반 수동 교체는 위치와 방향을 유지합니다. 시작·보상·상점방에는 전투용 양쪽 우회 조건을 강제하지 않습니다. 기존 개수 유지 모드에서 모든 후보가 실패하면 요청 수량을 보존한 채 생성을 거부합니다. 선택한 프리팹의 위치·회전 후보를 모두 검사한 뒤 다른 프리팹을 시도하므로 가까운 곳에 맞는 작은 소품이 먼 곳에 들어갈 큰 소품을 먼저 대체하지 않습니다.

자동 균형 구성은 배치 전 바닥 면적의 12%를 초기 목표로 사용합니다(1~30% 조절). 실제 외접 가로×깊이로 점유 면적을 계산하고, 충돌에는 반올림된 전체 직사각형 셀을 사용합니다. 소형은 수평 최장 길이 2m 미만, 중형은 2~4m 미만, 대형은 4m 이상이며 목표 면적 비중은 대형 50%·중형 35%·소형 15%입니다. 큰 소품을 먼저 놓고 중·소형을 주변에 분산합니다. 사용할 수 없는 크기의 몫은 다른 크기로 넘깁니다. 마지막 소품 하나로 목표를 소폭 초과할 수 있으며, 통행·천장·간격 때문에 부족하면 가능한 배치와 경고를 남깁니다. 이런 부분 결과에서 우회 전투 구성 자체가 부족한 것은 경고이며 출입·회피·연결 실패는 계속 오류입니다. 이 비중과 점유율은 프로젝트 초기 조정값입니다.

기존 파일에 새 모드 설정이 없으면 개수 유지로 열고 새 프로젝트만 자동 구성을 기본으로 합니다. 미측정 소품이 있으면 점유율은 계산 불가로 표시합니다. 영역 경계에 걸친 소품과 수동 배치·교체한 소품은 재생성 중 전체를 보존합니다. 영역 점유율에는 경계 소품의 실제 외접 직사각형과 선택 영역이 겹치는 면적만 포함합니다.

편집기의 소품 우회 경로와 직선 대비 추가 이동 거리는 이동 선택을 확인하는 기하학적 근거입니다. 장애물 뒤의 시야 차단·엄폐 효과·적의 추격 행동은 실제 메시, 콜라이더와 게임 AI에 따라 달라지므로 별도로 플레이테스트합니다.

## 기존 지형에 소품·장식 추가

에셋 탭의 명시적인 자동 배치 작업은 AI 생성과 분리합니다. 생성 당시의 소품·장식 토글과 관계없이 이번 작업에서 선택한 역할의 측정된 에셋을 사용합니다. 소품 점유율과 장식 밀도까지 추가하며, 기존 측정 배치물·잠금·직접 지정은 보존합니다. 등록만으로 배치하거나 저장된 맵을 열 때 자동으로 실행하지 않습니다.

외곽·바닥 높이·계단·다리·연결문·천장·구조·마커·구역은 유지합니다. 새 장애물이 생기는 셀의 바닥/소품 점유 표시만 바뀝니다. 원본 크기·회전·머리 위 여유·출입구·회피·필수 경로를 검사하고, 공간이 부족한 경우 가능한 배치와 제한 사유를 남깁니다. 역할·방 용도·테마·출현 가중치를 만족하는 에셋을 선택하며 모든 종류의 출현을 강제하지 않습니다.

## 자동 검사와 수동 플레이테스트

자동 검사는 높이를 반영한 격자 이동, 반경·머리 위 여유, 출입문 접근 공간, 회피용 평지, 실제 장애물 양쪽 우회로, 최고 지대의 별도 계단 접근, 필수 목적지의 안전한 경로, 잠금문 이전의 스위치 접근을 확인합니다. 소품 전체 점유 셀과 기둥·닫힌 게이트를 통행에서 제외합니다. 연결문이나 보상으로 가는 필수 경로를 위험 바닥과 함정이 차단하면 오류입니다. 실패 시 지형을 임의로 평탄화하거나 명시된 수량을 줄이지 않습니다. 자동 균형 구성의 점유율은 가능한 안전한 배치를 우선하는 목표값입니다.

게임에서 다음을 직접 확인합니다.

1. 모든 문으로 들어가 카메라 시야, 문틀 충돌, 첫 적과의 거리, 바닥 단차와 계단 오름을 확인합니다.
2. 대표 교전 위치에서 네 방향 회피를 실제 컨트롤러로 수행합니다. 회피 중 충돌·무적 시간·애니메이션 이동량은 격자 검사에 포함되지 않습니다.
3. 장애물 양쪽 동선과 고지의 두 접근로가 전투에서 실제로 다른 선택을 만드는지 확인합니다. 적 AI·사거리·압박은 별도로 조정합니다.
4. 위험 지형을 피해 보상·상인·스위치에 접근하고 잠금문을 열 수 있는지 확인합니다.
5. 소형·중형·대형·보스방에서 전투 시간과 빈 이동 시간을 관찰하고 기본 규격을 조정합니다. 시작·보상·상점방에는 전투 공간 조건을 강제하지 않습니다.

회피 검사는 평지의 네 축을 대상으로 하며 모든 위치·모든 각도에서의 회피를 보증하지 않습니다. 이동 그래프는 Unity NavMesh나 연속 충돌 시뮬레이션이 아닙니다. 실제 프리팹 메시·콜라이더의 적합성은 Unity에서 확인합니다.
