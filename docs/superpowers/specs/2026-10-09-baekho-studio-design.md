# 백호툴 통합 설계

사용자 요청: 별도 통합 브랜치에 편하고 단순한 UI를 만들고 3D 제작과 타격감 도구를 함께 사용한다. 기존 승인된 UX 지침을 적용한다.

## 사용자 흐름

- 공통 메뉴는 홈 / 도구 / 실행 / 결과 / 설정. 홈에는 두 도구와 실제 최근 작업을 제공한다.
- 각 도구는 같은 앱 창에서 열리며 공통 탐색을 유지한다. 화면 이동으로 입력, 선택, 실행을 초기화하지 않는다.
- 실행 목록과 결과 목록은 기존 저장소의 데이터를 조회한다. 미확인 결과를 성공으로 표현하지 않는다. 항목을 누르면 원래 도구의 해당 프로젝트 또는 실험으로 돌아간다.
- 설정에서 각 도구의 연결 설정과 저장 위치를 확인한다. 모델링 프로젝트와 Unity 실험 프로젝트를 같은 데이터라고 가정하지 않는다.
- 사용자 생성/실행 버튼을 누르기 전에는 AI 생성, 유료 요청, Unity 실행을 시작하지 않는다.

## 구조

Electron + React 기반 Partsmith 호스트를 재사용한다. Partsmith App은 embedded 모드로 유지하고 공통 React shell 안에 계속 마운트한다. Combat Lab은 자체 preload 및 보안 경계를 유지하는 WebContentsView로 같은 창 안에 표시한다. Combat 서비스를 독립 앱 생명주기에서 분리해 통합 호스트에서 한 번 초기화한다. 전환 시 view를 숨기며 종료하거나 다시 로드하지 않는다.

기존 Partsmith package identity와 기본 데이터 경로를 보존한다. Combat 설정은 별도 파일에 저장하고 기존 Baekho Studio 설정은 필요한 경우 처음 한 번 읽어온다. 테스트는 별도 임시 데이터 경로에서 수행한다. 기존 브랜치의 기능은 merge history와 별도 도구 설명서로 보존한다.

## UI

차콜 탐색 영역, 밝은 중성 작업 배경, 절제된 주홍색 강조를 사용한다. 홈에서 큰 두 도구 카드로 바로 시작하고 빈 상태에 다음 행동을 제공한다. 불필요한 통계와 가짜 예시 데이터를 넣지 않는다. 한 화면의 주요 행동을 명확하게 구분하며 키보드 포커스, 한국어 줄바꿈, 작은 창 크기를 확인한다.

## 검증

기존 두 도구의 테스트, TypeScript 빌드, 통합 상태 매핑/보안/경로 테스트, 실제 Electron에서 두 작업 화면 열기·전환·입력 보존·결과 재열기·오류 표시, Windows 패키지 실행을 확인한다. 유료 생성 및 실제 게임 프로젝트 변경은 이 통합 검증에 포함하지 않는다.
