# 정적 사물의 누락 평면 복구

## 사용 방법

모델 미리보기에서 **수정하기 → 빠진 면 검사**를 엽니다. 새 모델은 로컬 검사 결과를 준비하며, 기존 모델은 이 화면에서 검사를 실행합니다. 검사만으로 모델이나 현재 사용하는 결과는 바뀌지 않습니다.

1. 원본 이름과 참고 이미지를 확인하고 검사합니다.
2. 메시가 여러 개면 이번에 복구할 메시 하나를 고릅니다.
3. 번호로 표시된 열린 부분마다 **막을 부분 / 원래 열린 부분·유지**를 선택합니다. `영역 N 확대`로 위치를 확인합니다.
4. 추가할 면과 재질 방식을 확인하고 **선택한 부분 복구**를 누릅니다.
5. 같은 시점의 전후 비교에서 방향·겹침·무늬를 확인합니다. 만족하면 **이 복구본 사용**을 누릅니다.

결과 사용은 텍스처 생성이나 Unity 전달을 자동으로 시작하지 않습니다. 기존 채택본과 원본 파일은 남습니다. 앱의 검사·복구·UV·내보내기 처리는 로컬 코드이며 제작용 GPT와 외부 유료 서비스를 호출하지 않습니다. 앱 개발에 사용한 Codex 대화와는 별도입니다.

## 지원 범위와 차단

- BLEND/FBX의 독립적인 정적 메시. 선택한 메시의 3–64 정점으로 이루어진 단순한 닫힌 평면 경계.
- 삼각 경계는 삼각면, 볼록한 사각 경계는 사각면, 나머지 단순 평면 경계는 삼각 분할.
- 기존 정점·면 연결을 유지하고 면만 추가합니다. 다른 열린 부분과 메시를 임의로 닫지 않습니다.
- 분기된 경계에서는 막다른 가지를 제외한 뒤, 남은 경계가 단순한 닫힌 윤곽일 때만 별도 후보를 제공합니다. 제외한 열린 선은 `그대로 둘 열린 선`으로 구분하며 임의로 막지 않습니다.
- 가지를 제외해도 순환 경계가 복잡하게 갈라지거나 서로 공유되는 경우, 뒤틀림·중복 좌표·자가 교차·중첩 경계·기존 표면 관통은 차단합니다. 여러 선택 면 사이의 교차도 실행 시 다시 검사합니다.
- 리그·스킨·모프·애니메이션·부모 변환·미적용 모디파이어·외부 연결·다중 장면 등 대응을 명확히 확인할 수 없는 자료는 차단합니다.
- 한 입력의 메시 64개, 전체 원본 면 250,000개, 메시별 열린 경계선 4,096개와 교차 검사량 상한이 있습니다. 상한을 넘으면 완료로 처리하지 않습니다.
- 경계가 없다는 결과는 의도한 모든 면이 있다는 뜻이 아닙니다. 뒤집힘·투명도·중복 표면·가려짐은 별도 원인일 수 있습니다. 이 검사로 면을 무조건 추가하지 않습니다.

원본 단위는 임의로 미터로 확정하지 않습니다. 평면 판정은 경계 크기에 대한 상대 오차를 사용합니다. 기하 계산, 교차 검사와 내보내기 검증의 통과가 외형 품질을 보증하지는 않습니다.

## UV·재질

**텍스처 없는 원본:** 작업 사본에 로컬 UV를 준비하고, 기존 UV 층은 원본과 편집용 파일에 보존합니다. 내보내기 사본의 활성 UV는 하나로 고정합니다. 유효한 UV와 보기 좋은 패킹·무늬는 구분합니다.

**텍스처 있는 원본:** 기존 면의 UV·재질·압축 전 원본 이미지 바이트를 보존합니다. 한 개의 명확한 UV 층과 호환되는 평면 매핑을 확인할 때만 기존 매핑을 연장합니다. 기존 UV 영역과 겹치는 연장은 차단합니다. `기존 무늬 재사용`은 별도 선택이며, 호환되는 모양의 기존 면 무늬를 공유하므로 반복·늘어짐·이음새 차이가 생길 수 있습니다. 연결할 방법이 없으면 차단하고 임의의 회색 면으로 완성 처리하지 않습니다.

전체 UV 재배치·새 AI 텍스처·곡면 재구성은 이 기능에 포함하지 않습니다. 기존 `surfaceRepair`와 M09 원본·기록도 변경하지 않습니다.

## 실제 상자의 큰 구멍

검증 입력은 상자의 **보완 전 FBX 복사본**입니다. 원본 버전 `7d228d37`, SHA-256 `4789cf60edc4cbce452a855da92b37a160a012b32e6aa67602f6af174b0b99a8`, 기존 966정점·1,208면입니다.

이전 `planar-v1` 검사는 큰 구멍과 옆의 두 열린 선을 하나로 묶어 차단했습니다. `planar-v2`는 막다른 가지를 제외하고 실제 사각형 윤곽을 따로 찾습니다. 이 상자의 큰 구멍은 평면 오차가 0인 볼록 사각형이며, 주변 면과의 접촉은 공유 모서리·정점에 한정됩니다. 기존의 일부 교차 오탐도 실제 평면 절단 구간을 계산하도록 수정했습니다.

이 원본의 새 검사에서는 큰 구멍이 **영역 5 · 갈라진 경계 안의 닫힌 고리**로 표시됩니다. 위치는 번호만 믿지 말고 색상 표시와 확대 화면으로 확인합니다. 큰 구멍만 선택하면 사각면 1개가 추가됩니다. 남은 열린 선과 다른 구멍은 유지합니다. 실제 관통이 있는 다른 두 경계는 계속 차단됩니다.

기존 무료 텍스처 복구 후보 `b52c1b3e`에는 이전 보완 작업으로 큰 사각면과 유효 UV가 이미 있습니다. 이 결과에 같은 면을 또 추가하지 않습니다. 새 기능의 기하 복구 검증은 **보완 전 원본 복사본**을 사용하며, 기존 M09·텍스처·채택 기록은 변경하지 않습니다.

## 실행 기록과 복구

원본 버전·해시, 검사 보고서 해시, 도구와 Blender 파일 해시, 알고리즘 버전, 선택·유지 경계와 재질 정책을 고정합니다. 검사 결과는 모델 후보로 등록하지 않습니다. 복구 결과는 별도 `planarRepair` 출처가 있는 미채택 버전입니다.

- 중복 클릭은 동일 실행 기록을 사용합니다.
- 실패한 동일 요청을 자동 재실행하지 않습니다. 명시적으로 새로 검사한 요청은 별도 실행입니다.
- 저장된 결과 복구는 완료 파일의 검사·등록만 하며 Blender 제작이나 원격 제출을 다시 하지 않습니다.
- 원본 변경·도구 변경·불완전한 출력·필수 보존 검사 실패는 차단합니다.
- 실패한 영역을 몰래 제외해 부분 성공으로 채택하지 않습니다.
- 옛 `planar-v1` 검사로 새 복구를 실행하지 않습니다. `이 원본 다시 검사`로 새 검사를 준비합니다. 이미 완료된 이전 복구본은 별도로 비교·사용할 수 있으며, 원본과 보고서의 연결 및 필수 검사 기록을 확인합니다.

저장소의 자동 검사와 격리된 앱·Unity 프로젝트로 확인합니다. 실제 운영 프로젝트에서 자동 채택하지 않습니다.

- `tests/graphics-planar.test.ts`: 파일·요청·완료 결과 고정, 중복·취소·복구.
- `tests/graphics-planar-coordinator.test.ts`: 기존 엔진 연결, 검사와 모델 등록 분리, 채택·원본 보존.
- `tests/graphics-planar-native.test.ts`: 실제 Blender 기하·UV·재질·FBX/GLB 재가져오기.
- `tests/graphics-planar-ui.test.ts`: 영역 선택·오류·재검사·초안·화면 크기.
- `scripts/graphics-planar-app-check.ts`: 실제 Electron 앱 버튼과 격리된 상자 사본.
- `scripts/graphics-planar-unity-check.ts`: 실제 Unity 가져오기·재전달·사용자 설정 보존.
- `scripts/graphics-planar-production-audit.mjs`: 운영 기록과 등록된 원본 파일 보존.

실행별 결과는 `artifacts/runtime/graphics-planar-*`에 기록합니다. 실제 신규 사용자 사용성, Windows 모니터별 DPI와 모든 사물의 외형 품질을 인증하는 기능은 아닙니다.
