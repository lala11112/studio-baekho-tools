# 화면 일관성 개선 — preview.13

이번 변경은 제작 기능을 재설계하지 않고, 홈·연결 설정·오브젝트 제작 화면의 글자와 간격, 실행 위치를 정리한다.

## 공통 기준

- 글꼴: Segoe UI / 맑은 고딕 계열. 본문 13px, 보조 설명 12px, 영역 제목 15px, 화면 제목 18px.
- 버튼: 기본 높이 32px, 주요 실행 36px. 입력은 최소 34px이며 긴 내용은 필요한 높이를 유지한다.
- 간격: 4·8·12·16·24·32px 공통 값. 패널 배경과 테두리도 같은 색상 기준을 사용한다.
- 강조색은 선택 상태와 주요 실행에 사용하고, 정보·설명은 차분한 패널에 배치한다. 경고 문구와 진행·승인 상태는 유지한다.

## 사용자가 보는 변화

1. 홈은 프로젝트 목록과 새 프로젝트 진입을 중심으로 정리한다. 중복 소개와 큰 장식 제목을 줄인다.
2. 제작 단계 바로 아래에 실행 버튼과 대상·도구·후보·면 수·크기·비용 요약을 한 카드로 모은다.
3. 대상 목록, 단계 이동, 설정, 결과 패널의 제목과 여백을 통일한다. 결과의 여러 주의 문구는 ‘검토할 사항’으로 묶되 모두 표시한다.
4. 모델 보기 도구는 시점 / 표면 / 메시 / 보조 표시로 구분한다. 뼈대·치수·원본 면 선 등 기존 표시 동작은 유지한다.
5. 새 오브젝트 창의 선택 카드·이름 입력·하단 버튼, 면 수 설정도 공통 기준을 따른다.
6. 좁은 화면은 세로 스크롤로 내용과 실행 영역에 접근한다. 단계 이동은 가로 스크롤을 사용한다.

선택·채택·생성·비용 승인·복구의 처리 방식은 바꾸지 않는다. 화면 확인 중 새 이미지·모델·동작 생성과 유료 요청을 실행하지 않는다.

## 확인 근거

- 실제 Electron에서 홈·연결 설정·7개 제작 단계·새 오브젝트 창을 5개 창 크기/확대 조합으로 확인: 50화면.
- 1920×1080/1280×900(100%), 960×900(125%), 800×900/1280×900(150%). 작은 폭은 검사창의 최소 크기 제한만 풀어 실제 폭으로 검증했다.
- 현재 Windows 배율은 150%이며 위 확대율은 앱 확대다. OS 배율을 각각 변경한 검증으로 표현하지 않는다.
- 가로 넘침·제목/실행 버튼 가림·하단 생성 버튼 접근·글자/입력 크기를 검사하고 Electron 원본 캡처로 육안 확인했다.
- 별도 폰트 검사에서 실제 한글 글리프는 Malgun Gothic, 영문은 Segoe UI로 확인했다. CSS 선언만 확인한 것이 아니며 근거는 `graphics-preview13-fonts.json`이다.
- 실제 프로젝트 복사본을 사용하되 변경 IPC와 외부 네트워크는 차단했다. 원본 42개 파일과 기존 프로젝트·작업·채택 기록을 비교했다.
- 최초 캡처는 Playwright의 확대 캡처와 창 최소 크기 때문에 검증 범위가 부정확했다. 검사기를 수정하고 실제 작은 폭 및 Electron capturePage로 최종 검증했다.

자동 검사 보고서는 `artifacts/runtime/graphics-preview13-ui.json`, 실제 앱 교체 확인은 `artifacts/runtime/graphics-preview13-live.json`, 배포 로그는 `artifacts/runtime/graphics-preview13-final-package.log`에 남긴다.

새 배포본은 `release/0.7.0-preview.13/win-unpacked`이며 폴더 전체를 유지한다. 이번 작업에 저장 공간 정리나 기존 배포본 삭제는 포함하지 않는다.
