# 목·헤어 국소 구조 보정

**최신 사용자 방향:** 임시 조립은 크기·위치·방향과 큰 형상 결함 확인까지다. 파트별 UV·텍스처 후 최종 조립에서 미세 위치·작은 관통·접합을 다듬는다. 구멍이나 누락 면처럼 UV 구성을 바꾸는 구조 문제만 UV 전에 구분한다. 현재 한 번 만든 보정 후보는 보존하되 추가 보정을 하지 않으며, 어떤 모델을 재질 입력으로 채택할지는 사용자가 결정한다.

기존 고정 면 보정으로 처리할 수 없는 접합을 별도 요청으로 검토한다. 기존 분석을 다시 실행하거나 차단된 영역을 그대로 허용하지 않는다.

## 앱 동작

저장된 접합 분석의 `목·헤어 구조 보정 준비` → 입력·사용량 확인 → 한 번 실행 → 같은 구도의 전후 비교 → 사용자 채택 순서다. 원본과 기존 채택은 유지한다. 새 결과의 전체 조립과 배치된 머리·몸통·머리카락은 함께 채택하며, 개별 파트만 잘못 채택하지 못하게 한다.

보정 완료 카드와 `새 보정 결과 보기`는 이전 진단을 보고 있어도 유지된다. 보기·준비·채택만으로 다음 작업을 자동 실행하지 않는다. 실패 후 복구는 저장된 결과 검사만 수행하며 작업자를 다시 시작하지 않는다.

## 이번 제한

- 몸통·의상 전체, 머리의 얼굴·귀와 허용 목 영역 외 정점은 정확히 보존한다.
- 이전 분석에서 확인한 머리 목 범위를 원본 해시·면 연결·파트 버전과 대조한다.
- 머리 표면 가까이 있는 헤어 정점을 로컬에서 계산하고, 헤어 크기 대각선의 1% 이내 이동만 허용한다. 헤어 윤곽의 작은 변화는 가능하므로 외형 비교가 필요하다.
- 기존 면·모서리 순서·UV·재질·속성·식별자·배치는 유지한다. 허용된 원래 경계에 연결되는 작은 면과 정점을 추가할 수 있다. 파트당 최대 256정점·512면이며 실제 허용 범위와 거리·모서리 길이를 함께 검사한다.
- 새 면의 UV·텍스처, 리깅, 전체 재토폴로지, 새 모델 생성은 수행하지 않는다. 관통 해소·해부학·외형 품질은 수치 보존 검사와 별도로 검토한다.

## 실행과 복구

조립본, 같은 작업에서 나온 세 파트, 기존 분석과 파일 해시를 요청에 고정한다. 보정 범위와 준비 기록의 해시를 작업자 실행 전에 저장하고 실행·복구 시 다시 확인한다. 제작용 Astra는 한 번만 호출하며 기존 모델·추론 설정을 유지한다. Tripo·fal 호출은 없다. 통신 내부 재연결과 새 작업자 실행은 구분한다.

실제 파일 검사·범위 생성·렌더·내보내기·등록·복구는 로컬 코드로 처리한다. 새 면은 Unity 준비 완료나 UV 완료로 표시하지 않는다.

## 검증

관련 조정기 57개, 기존 조립·작업공간 26개, 실행·복구 32개, 네이티브 5개, 실제 Electron 화면 2개가 통과했다. 네이티브 검사는 실제 Blender의 국소 추가 면, 보호 영역 변경 거부, 원래 UV·파트 보존과 FBX 파트 내보내기를 포함한다. 화면 검사는 실행 중에서 완료로 바뀐 후 새 결과 버튼이 남는 동작을 포함한다.

실제 모델의 로컬 사전 검사에서는 목 230개·헤어 60개 정점이 범위에 포함됐고, 몸통은 0개다. 면 추가가 가능한 허용 경계는 목 38개·헤어 13개였다. 이 결과는 수정 가능한 범위의 증거이며 접합 품질 개선 성공을 뜻하지 않는다.

실제 제작 결과는 `artifacts/runtime/graphics-contact-reconstruction-live.json`과 해당 앱 작업의 원본 검사 보고서에서 별도로 기록한다.

## 실제 실행 결과 — 2026-10-14

앱 M06 `0d3e1522-7949-406b-87e9-2ed14a25d2ff`에서 Astra를 한 번 실행했다. 저장 전 Blender 5의 읽기 전용 `MeshPolygon.loop_total` 대입 오류가 발생했다. 실패한 원본 절차·응답·사용량·중단 결과는 보존했다.

앱의 `호환 오류 복구 · 추가 GPT 없음`은 이 사건의 정확한 스크립트 해시와 오류를 검사한다. 별도 복사본에서 해당 대입 한 줄만 제외하고 나머지 AST·소스 줄이 동일함을 증명한 뒤, 실행 기록을 먼저 저장하고 로컬에서 한 번 실행한다. 이미 실행 기록이 있으면 다시 실행하지 않는다. 원래 제작 요청·설정·사용량은 바꾸지 않는다.

복구한 후보 `d2736761-70a5-45d9-994d-f039d9815a2a`와 배치된 세 파트를 앱에 등록했다. 채택은 하지 않았다. 읽기 전용 독립 검사 23개에서 원본·보호 영역·UV·재질·식별자·배치를 확인했다.

- 목 230정점 이동, 38정점·38면 추가.
- 헤어 27정점 이동, 9정점·6면 추가. 몸통은 전체 동일.
- 최대 이동 0.004662 원본 좌표 단위. 미터 단위로 확정한 값은 아니다.
- 같은 헤어 표본 60개 중 음수 최근접 표면 거리 표본은 11→4개로 감소했다. 큰 면 관통까지 없다는 증거는 아니다.
- 새 면의 UV 176코너는 임시값이다. UV·텍스처 완료가 아니다.

전후 화면에서는 목의 벌어짐이 줄었지만 전면 목 경계와 헤어 안쪽의 거친 구조가 남았다. **파일 보존 검사는 통과했지만 접합 외형 합격으로 판정하지 않았다.** 자동 재보정·채택·UV·텍스처·리깅은 진행하지 않는다. Tripo·fal 추가 비용 0, 인간형 검증 장부 240/300크레딧 유지. 초기 Astra 사용량과 호환 복구의 추가 GPT 0회는 구분한다.

추가 검증: 조정기 68개, 실행 복구 38개, 실제 Electron 화면 2개 통과. Blender 호환 복사본의 합성 검사 16개와 실제 후보 독립 검사 23개 통과. 기존 조립·작업공간 및 네이티브 보존 검사도 유지한다. 증거는 `graphics-contact-reconstruct-actual-audit.json`, `graphics-contact-loop-compatibility-proof.json`, `graphics-contact-reconstruction-live.json`에 기록한다.
