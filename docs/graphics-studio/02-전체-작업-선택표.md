# Partsmith 전체 작업 선택표

검토용 초안 1.0 · 2026년 10월 12일

**아래 항목은 모두 ‘사용자가 직접 편집하는 메뉴’가 아니라, 선택하면 앱이 수행할 자동 작업의 설계입니다.** 기본은 작업 선택→앱 수행→결과 확인→사용자 채택입니다. 이 표에 있다고 현재 구현·연결이 완료된 것은 아닙니다.

표의 묶음은 전체 기획서의 개발 순서입니다. **B 공통 작업 공간 / C 정적 에셋 / D 캐릭터·모션 / E 2D·UI / F 환경·VFX**. 묶음 완료 후에도 실제 검증을 통과해야 ‘사용 가능’이 됩니다. 고급 작업도 제품 범위에는 포함하지만 선행 도구·품질 검증을 생략하지 않습니다.

처음 만들 작업은 기본 꺼짐이며, 사용자가 프리셋을 고르면 관련 항목만 선택됩니다. 가져온 파일에 이미 있는 결과는 재생성하지 않습니다. ‘안 켜면 파일이 사라짐’ 같은 토글은 없습니다. 검토 의견은 `M04 유지`, `R07 수정: 치마 포함`, `X05 제외`처럼 ID로 전달할 수 있습니다.

## 자동 검사와 표시 토글

검사는 결과 종류에 따라 기본 수행하되, 사용자가 추가 검사도 선택할 수 있다. 파일 존재·해시·출처·안전한 경로·요청 개수·비용 기록 검사는 끌 수 있는 품질 옵션이 아니다.

| 종류 | 제공 항목 |
|---|---|
| 추가 이미지 검사 | 알파 경계, 크기 일치, 시점 일관성, 픽셀 격자, 타일 반복 |
| 추가 모델 검사 | 실제 면 수, 노멀, 구멍, 중복, 관통, 비다양체, 얇은 구조 |
| 추가 표면 검사 | UV 겹침/밀도, 텍스처 누락, 실제 해상도, 색 공간, 재질 슬롯 |
| 추가 모션 검사 | 웨이트, 관절 변형, 접지, 루프, 루트 이동, 참조 타이밍 |
| 추가 엔진 검사 | 재질·리그·클립·UI 비율·VFX 재생·성능·플랫폼 호환 |
| 무료 표시 토글 | 참고 이미지, 와이어, 뼈대, UV, 면 방향, 그리드, 축, 장착점, 충돌체, 조명, 알파 배경, 루프, 전후 비교 |

표시 토글은 서비스 제출이나 GPT 호출을 만들지 않는다. ‘무료’는 이 로컬 표시 조작에 한정하며 원본 제작 비용을 뜻하지 않는다.

## 공통 설정의 기본 규칙

| 설정 | 기본값과 동작 |
|---|---|
| 후보 개수 | 1. 실제 서비스 지원 수와 호출 수 표시. 이미지·모델·클립·파츠 세트 개수를 구분 |
| 이미지/텍스처 해상도 | 가져온 원본 보존. 새 생성은 지원 해상도를 선택하며 기존 설정을 자동 하향하지 않음 |
| 스타일 | 명시한 스타일·참조 우선. 미입력 시 과도한 임의 스타일 부여 금지 |
| 모델 입력 | 단일 이미지 기본. 멀티뷰·파츠 분리는 선택 |
| 면 수 | 목표와 실제 결과 별도. 삼각환산과 사각면 기준 함께 표시 |
| UV | 기존 유효 UV 보존. 새 생성/재배치는 명시 선택 또는 표시된 표면 작업 범위에 포함 |
| 리그 | 대상에서 제안 후 표시. 동물은 Generic, 사람도 Humanoid 검사를 통과해야 해당 출력 |
| 영상 | 동작 참고는 측면·720p를 기본 제안. 서비스 지원 길이와 최종 3D 클립 길이를 구분 |
| 3D 클립 | 30fps 기본 제안, 동작별 길이 설정. 제자리/루트 모션은 배타 선택 |
| 압축·경량화 | 최종 원본에 자동 적용하지 않음. 사용자가 선택한 게임용 사본에만 적용 |
| 다음 작업 | 결과 채택 뒤 준비 상태. 사용자가 다음 실행을 눌러 시작 |
| GPT 품질 | 사용자 설정 유지. 토큰 절약을 이유로 모델·추론·참조 해상도 하향 금지 |

## 함께 켤 수 없는 설정과 자동 안내

- 같은 출력의 ‘기존 UV 유지’와 ‘UV 새로 생성’은 하나만 선택한다.
- 하나의 클립의 ‘제자리’와 ‘루트 이동’은 하나만 선택한다. 둘 다 원하면 별도 출력으로 만든다.
- 메시 구조 변경과 ‘현재 웨이트·블렌드셰이프 그대로 유지’는 호환 검사 없이는 약속하지 않는다.
- 시점 이미지 생성과 한 장의 비교 시트 생성은 다르다. 독립 원본 요청을 시트 분할로 대체하지 않는다.
- P2·HD 등 모델별로 지원하지 않는 설정은 숨기거나 이유와 함께 비활성화한다.
- ‘참고 자료’는 생성/수정할 대상이 아니다. 새 오브젝트 요청과 원본 수정 요청을 구분한다.
- 이미지·영상만 만들면 모델·리깅은 필요 없다. 정적 모델을 Unity로 보내면 리깅·모션은 필요 없다.
- 물리, 표정, 추가 방향, 추가 동작, 새 후보는 사용자가 요청한 범위에서만 생성한다.

## 검토 답변 양식

원하는 항목만 적으면 된다. 작업별 기술 구현 방법까지 결정할 필요는 없다.

```text
우선 보고 싶은 사용 장면:
꼭 있어야 하는 작업 ID:
수정할 작업 ID와 내용:
없어도 되는 작업 ID:
목록에 없는 요청 예시:
결과를 볼 때 꼭 필요한 비교/검사:
한 작업에서 자동으로 처리되었으면 하는 범위:
```

다음 개정에서는 의견을 반영한 전체 선택표와 바뀐 부분을 함께 제공한다.
