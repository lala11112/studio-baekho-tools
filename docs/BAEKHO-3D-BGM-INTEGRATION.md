# 백호툴 0.9.0 · 최신 3D + BGM 통합

## 전달 구성

`integration/baekho-bgm`은 최신 `Auto-3D-Tool`의 `57a6aee`에 `codex/bgm-generator`의 `fa53929`를 병합한 별도 통합 브랜치입니다. 기존 통합 앱의 Combat Lab·AutoHitTimer도 보존했습니다. `main`, `Auto-3D-Tool`, `integration/baekho-studio`, 사인검·BGM 기능 브랜치는 변경하지 않았습니다. 최신 별도 AutoMapPrefabMaker나 이후 AutoHitTimer 기능은 임의로 합치지 않았습니다.

기존 실행 파일을 교체하지 않습니다. `Baekho-3D-BGM-0.9.0` 폴더의 `App`, `Data`, `OriginalDataSnapshot`, `Verification`, `Launch-Baekho.vbs`, `사용법.md`를 함께 보관합니다. 바탕화면 **백호툴 - 3D·BGM 통합**은 실행기를 통해 이 폴더의 `Data`를 사용합니다. 기존 데이터는 원본과 변경하지 않은 사본으로 유지하고, 이미 생성한 세 곡만 새 Data에 복사합니다. 비밀키는 기존 환경 변수를 메모리에서 읽으며 새 평문 키 파일을 만들지 않습니다.

## 통합 범위

- 홈의 네 도구: 최신 Unity 그래픽 제작, 타격감, 타격 타이밍(개발 중), BGM 만들기.
- 3D 엔진·GraphicsStudio·Viewport·Blender 리소스는 `57a6aee` 그대로 보존. 호스트와 앱 탐색만 통합하며 기존 단계별 제작실도 유지합니다.
- 그래픽 작업·결과가 공통 실행/결과 목록에 표시됩니다. 복구 결과, 실제 채택 버전, 아직 검증하지 않은 Unity 가져오기 상태를 구분합니다.
- 최신 FFmpeg 리소스 및 기존 타격감/타격 타이밍 패키징 리소스 보존.
- BGM 모델·생성·비용·보관은 [BGM 사용법](BGM-GENERATOR.md) 참조.

## 실제 확인한 검증

- 기존 타격감 118개, 타격 타이밍 48개 로컬 테스트 통과.
- 전체 Node 테스트 최초 실행: 879개 보고, 837 통과, 4 실패, 38 생략. 생략에는 실제 Blender 실행 환경이 필요한 검사가 포함됩니다.
- 실패 원인: 최신 M09 기능·중립 축 명칭을 반영하지 않은 기존 테스트 3개와 Windows Node 24의 한글 경로 `fs.cpSync` 테스트 데이터 복사 충돌 1개. 앱 엔진을 바꾸지 않고 기대값과 테스트 복사 방식을 수정했습니다.
- 실패 영역과 통합 요약 집중 재검증 38개 통과: catalog/head UI 8개, Unity 모의 전달 12개, Studio/Graphics 요약 18개. 불필요한 전체 재실행은 하지 않았습니다.
- TypeScript 검사, Vite/Electron 빌드, Windows 폴더 패키징 통과. 대형 JS chunk 경고는 남아 있습니다.
- 개발/배포 Studio 검증 각각 14개 통과. 네 도구와 격리된 native bridge, 입력 유지, 기존 저장·결과 동선을 검사했습니다.
- 개발/배포 3D+BGM 전용 검증 각각 8개 통과. 최신 그래픽 화면과 미제출 초안 유지, 세 곡 로컬 재생·선택·내보내기·재시작, 원본 해시 보존, renderer 오류 0 확인.
- 음악 내보내기 6회(세 곡 × 재시작 전후) 모두 기존 MP3와 SHA-256 일치. 각 파일의 재생 길이는 약 30.77초이며 다시 생성하지 않았습니다.
- 새 폴더 복사 검사: 기존 데이터 66개 파일, 기존 BGM 7개 파일, 패키지 213개 파일 해시 일치. 새 바로가기 실제 실행에서 전용 Data 사용을 확인했고 기존 프로필 66개 파일은 변하지 않았습니다.

실제 설치본의 최종 상세 기록은 전달 폴더 `Verification`에 보관합니다. 검증용 프로필·음원은 git에 넣지 않습니다.

## 비용과 남은 범위

이 통합 작업의 유료 생성·재시도는 **0회**, 추가 비용은 **USD 0**입니다. 앞선 BGM 구현 검증은 Google Lyria 3 오디오 3회 × USD 0.04 = **예상 USD 0.12**였으며 전체 승인 한도 USD 5 미만입니다. fal API가 확정 청구액을 반환하지 않아 실제 결제 금액으로 단정하지 않습니다.

통합 검증은 최신 3D 기능의 모든 유료 제작, 실제 Unity 게임 실행, 음원의 음악적 품질·완전한 루프를 다시 검증했다는 의미가 아닙니다. 실제 진행 중이거나 승인 대기인 기존 제작 작업은 건드리지 않았습니다. 코드 서명/설치 프로그램 없이 폴더 앱을 제공합니다.
