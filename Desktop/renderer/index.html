테스트할 동작 · 여러 개 선택 가능
같은 원본의 동작을 선택하세요. 전체 콤보와 개별 일반 공격은 함께 선택할 수 없습니다.
Unity에 연결하면 프로젝트 어댑터가 제공하는 실험 데이터를 읽어옵니다.
다른 Unity 프로젝트 연결하기

처음 연결하는 프로젝트는 도구 저장소에서 아래 명령을 실행하고 Unity에서 프로젝트를 여세요. Example은 연결 확인용이며, 실제 게임의 전투를 실험하려면 해당 게임의 어댑터가 필요합니다.

.\scripts\Install-CombatLab.ps1 -UnityProject "프로젝트 경로" -Adapter Example

설치가 끝나면 프로젝트를 선택하고 연결 정보를 새로고침하세요. 기존 게임의 어댑터 설치 방법은 저장소의 README를 참고하세요.
