# Four-Tiger-Sword v2 실행부 통합 자료

현재 개발 중인 게임 체크아웃에는 아래 변경이 이미 통합돼 있습니다. **같은 체크아웃에 다시 적용하지 마세요.** 이 폴더는 다른 체크아웃에서 변경 내용을 검토하고 통합하기 위한 자료입니다. 설치 스크립트는 이 패치를 자동 실행하거나 게임 전투 소스를 덮어쓰지 않습니다.

- `four-tiger-combat-lab-v2.patch`: 카메라·명중·캐릭터 시간·고정 표적 준비에 필요한 게임 실행부 변경입니다.
- `manifest.json`: 변경 파일 46개와 신규 C#·meta 8개의 경로, 적용 전·후 바이트 SHA-256, 줄바꿈을 LF로 정규화한 텍스트 SHA-256, 포함 범위와 검증 결과입니다.

패치의 기준은 이번 작업 전에 보관한 **사용자의 기존 수정이 포함된 작업 파일**입니다. 특정 upstream 커밋을 기준으로 만든 패치가 아닙니다. 기존 수정은 패치가 새로 도입한 변경이 아니라 기준 문맥입니다. 캡처된 기준 파일이 없는 기존 파일, 기존 `.meta`, 씬·프리팹·SO·프로젝트 설정·Editor 진단 helper는 포함하지 않았습니다. 새 실행부 4개의 `.meta`만 신규 파일로 포함했습니다.

카메라 v2, 캐릭터 시계·히트스톱, 실제 명중·특수 동작 연결과 안정된 고정 표적 준비는 함께 필요합니다. 일부 파일만 덮어써서 사용하는 방식은 지원하지 않습니다. 공통 패키지와 Editor 어댑터는 상위 `UnityIntegration`의 설치 스크립트로 별도 설치합니다.

## 다른 체크아웃에서 검토하기

1. 대상 체크아웃의 현재 변경을 보관하고 별도 통합 브랜치에서 작업합니다. Unity는 종료합니다.
2. `manifest.json`의 수정 파일 `beforeSha256`와 대상 파일의 해시를 비교합니다. 신규 파일의 대상 경로에는 기존 파일이 없어야 합니다. 차이가 있으면 대상 변경을 유지하면서 수동 병합합니다. 기존 Unity `.meta` GUID를 바꾸지 않습니다.
3. 게임 프로젝트 루트(`Assets`, `Packages`, `ProjectSettings`가 있는 폴더)에서 먼저 검사만 실행합니다. 아래 명령은 파일을 수정하지 않습니다. 경로는 이 패치의 실제 위치로 바꿉니다.

```powershell
git -c core.autocrlf=false apply --check "C:/path/to/UnityIntegration/Integrations/FourTigerSword/RuntimeIntegration/four-tiger-combat-lab-v2.patch"
```

4. 모든 변경과 충돌을 검토한 뒤 프로젝트 소유자가 패치를 적용하거나 수동 병합합니다. 위 검사가 성공해도 대상 프로젝트의 컴파일과 실제 플레이 검증은 별도로 필요합니다. `--force`나 파일 전체 복사로 기존 변경을 제거하지 마세요.
5. 공통 패키지와 세 Editor 어댑터 파일을 설치하고 Unity 컴파일 후 [v2 검증 기록](../../../docs/combat-lab-v2-validation.md)의 실제 명중·로컬 정지·정밀 캡처·내보낸 SO 비교를 해당 체크아웃에서 다시 확인합니다.

이 패치는 보관된 기준 파일의 임시 복사본에서 `git apply --check`, 실제 적용, 54개 결과 파일의 바이트 해시 대조를 통과했습니다. 이는 패치 자료가 검증한 실행부 파일을 재구성한다는 검사입니다. 다른 체크아웃의 게임 실행 결과를 미리 보장하지 않습니다.
